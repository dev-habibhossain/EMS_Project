# Css

## Kiln defaults to paper ink and IBM Plex
The ERP chrome is light Kiln: paper #F3EFE8, ink #1C1916, IBM Plex Sans + Noto Sans Bengali, 14px root. Do not default appearance to system/OS dark — that puts light text on cream panels. Dark only when the user chose Dark. Do not load Instrument Sans. Borders use clay #D9D1C4, not gray-200. Native color-scheme is light unless html.dark.
